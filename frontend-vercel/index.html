URL parameters

?scene=<url>          load a scene.json from a URL (default: /scene.json or sample)
?live=<sse-url>       subscribe to SSE volume_frame stream (e.g. http://127.0.0.1:8765/api/stream)
?t_iso=<0..1>         filter voxels above this fraction of (vmax-vmin), default 0
?point=<px>           base point sprite size, default 14

Live with local backend

# 1) run the EA + sim-live server locally
python -m laser_sim sim-live --primitive zigzag --grid-n 24 --nz 12 --port 8765

# 2) tunnel it (cloudflared / ngrok)
cloudflared tunnel --url http://localhost:8765

# 3) open this Vercel deployment with the live URL
https://<deploy>/volume.html?live=https://<tunnel>/api/stream
